# DIX

Design Intelligence eXperience.

This repository contains the DIX V4 product concept page, built with self-contained HTML, CSS and JavaScript. `index.html` is the GitHub Pages entry point.

## Preview scope

The engineering workspace is an illustrative interaction demo, not a live EDA analysis service. It includes thermal review, component evidence and engineering constraint tabs. Calculations use explicitly stated sample assumptions.

## Development

Edit `index.html` and push to `main`. GitHub Pages deploys from the repository root.
